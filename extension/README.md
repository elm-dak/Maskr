# Maskr browser extension

Right-click any image on the web → **Redact with Maskr** → the image opens in the
Maskr app ready to redact. The image is fetched locally by the extension and
handed straight to the in-page tool — **nothing is uploaded to any server.**

## How it works

1. `background.js` adds a "Redact with Maskr" item to the image right-click menu.
2. On click it fetches the image bytes, converts them to a data URL, stashes it
   in `chrome.storage.local`, and opens the Maskr web app.
3. `content.js` (runs only on the Maskr domain) reads that pending image and
   dispatches a `maskr:load-image` CustomEvent.
4. The Maskr app listens for that event (`imgLoadDataUrl` in `index.html`) and
   loads the image — same code path as drag/paste.

If an image blocks cross-origin fetch (CORS), the extension still opens Maskr so
you can drag or paste it manually.

## Load it locally (development)

Chrome / Edge / Brave:

1. Go to `chrome://extensions`
2. Turn on **Developer mode** (top-right)
3. Click **Load unpacked** and select this `extension/` folder
4. Right-click any image on a page → **Redact with Maskr**

Firefox (temporary install):

1. Go to `about:debugging#/runtime/this-firefox`
2. **Load Temporary Add-on** → pick `extension/manifest.json`

## Maintaining it

- **Icons** are generated by `../gen-icons.cjs` (run `node gen-icons.cjs` from the
  repo root; it writes `extension/icons/icon-{16,48,128}.png`).
- **If the app moves to a custom domain**, update the URL in two places:
  - `MASKR_URL` in `background.js`
  - the `matches` entry in `manifest.json` (the content script must match the
    live domain or the handoff won't fire)

## Publishing (later)
